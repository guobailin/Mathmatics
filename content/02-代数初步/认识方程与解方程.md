## 讲解

**方程**：含有**未知数**的**等式**，如 $x + 3 = 9$。两个条件缺一不可：$3 + 5 = 8$ 不是方程（无未知数），$x + 3$ 也不是方程（不是等式）。

**方程的解**：使方程左右两边相等的未知数的值；求方程的解的过程叫**解方程**。

**解方程的依据**：等式性质。常见类型：
- $x + a = b \Rightarrow x = b - a$
- $x - a = b \Rightarrow x = b + a$
- $ax = b \Rightarrow x = b \div a$
- $x \div a = b \Rightarrow x = b \times a$
- 两步型 $ax + b = c$：先两边减 $b$，再两边除以 $a$。

**检验**：把解代入原方程，看左右两边是否相等——这是必须养成的习惯。

**易错点**：$3x = 0$ 的解是 $x = 0$，不是"无解"；解 $x \div 5 = 20$ 两边同乘 5，不是除以 5。

## 例题

### 例1：解一步方程
**题目**：解方程并检验：$x - 4.5 = 7.8$；$1.2x = 9.6$。

**覆盖点**：解一步方程

**解析**：$x - 4.5 = 7.8$，两边同加 4.5，$x = 12.3$。检验：$12.3 - 4.5 = 7.8$ ✓。$1.2x = 9.6$，两边同除以 1.2，$x = 8$。检验：$1.2 \times 8 = 9.6$ ✓。

**答案**：$x = 12.3$；$x = 8$

### 例2：解两步方程
**题目**：解方程：$3x + 6 = 27$；$5x - 12 = 48$。

**覆盖点**：解两步方程与检验

**解析**：$3x + 6 = 27$：两边同减 6 得 $3x = 21$，再同除以 3 得 $x = 7$。$5x - 12 = 48$：两边同加 12 得 $5x = 60$，$x = 12$。

**答案**：$x = 7$；$x = 12$
