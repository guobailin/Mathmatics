## 讲解

**等式**：用等号连接、左右两边相等的式子，如 $20 + 30 = 50$、$x + 3 = 9$。等式就像一架平衡的天平。

**性质 1**：等式两边**同时加上或减去**同一个数，等式仍然成立。
$$a = b \Rightarrow a + c = b + c$$

**性质 2**：等式两边**同时乘**同一个数，或同时**除以**同一个**不为 0** 的数，等式仍然成立。
$$a = b \Rightarrow ac = bc; \quad a = b \Rightarrow a \div c = b \div c \ (c \neq 0)$$

等式的性质是**解方程的依据**：解方程的每一步"两边同时……"都是在用这两条性质。

**易错点**：除以的数不能为 0；"同时"意味着两边必须做完全相同的操作，只动一边就破坏了平衡。

## 例题

### 例1：用等式性质填空
**题目**：如果 $x + 5 = 12$，根据等式性质填空：$x + 5 - 5 = 12 - (\quad)$；如果 $3x = 18$，则 $3x \div 3 = 18 \div (\quad)$。

**覆盖点**：等式性质1, 等式性质2

**解析**：左边减了 5，右边也要减 5；左边除以 3，右边也要除以 3。

**答案**：5；3

### 例2：判断变形是否正确
**题目**：已知 $a = b$。判断：① $a + 3 = b + 3$；② $a - c = b - c$；③ $2a = 2b$；④ $a \div c = b \div c$。

**覆盖点**：等式性质1, 等式性质2

**解析**：①②③分别用了性质 1 和性质 2，正确。④ 当 $c = 0$ 时不成立，题目没说明 $c \neq 0$，错误。

**答案**：①②③正确；④错误（未排除 c = 0）
