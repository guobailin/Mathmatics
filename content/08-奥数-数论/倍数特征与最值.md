## 讲解

**一、模型：两条约束的交汇。** 这类题同时给整除条件（可拆成"末几位"或"数字和/交错和"）与极值要求（最大、最小、最大与最小之差）。整除条件负责锁死一部分数位，极值要求负责把剩下的自由位排序。统一套路是：**拆特征 → 锁数位 → 列等式 → 逐位取极值 → 证明无更优 → 验算**。它能做成，是因为每条特征只看数位的一部分：末位系只看末几位，数字和系只看和，交错和系只看奇偶位和的差，剩余自由度有限，比较就能收口。

**二、为什么这些特征成立。** 以 $\overline{abcde}$ 为例。因为 $10\equiv1\pmod 9$，所以被 $3$ 或 $9$ 整除等价于数字和被 $3$ 或 $9$ 整除；因为 $10\equiv-1\pmod{11}$，故被 $11$ 整除等价于"奇位数字和减偶位数字和"是 $11$ 的倍数（差可正可负）。末位系来自 $100=4\times25$、$1000=8\times125$：判 $4$、$25$ 只需末两位，判 $8$、$125$ 只需末三位。合数必须拆成互质因数，如 $72=8\times9$、$44=4\times11$、$45=5\times9$；只有互质时"分别整除"才等价于"整体整除"。

**三、"最大/最小"怎么证明。** 极值题最怕"找到一个就交卷"，收尾要两层：其一，可行性上界——逐位说明当前位已取到该位置允许的最大数字，"取 9 可行吗"必须验，不可行才退到 8；其二，无遗漏——固定前缀，用总和减去已用数字，算出剩余位的和，说明剩余位怎么排都更小。求最小值还要多一层位数下界：数字和为 $S$ 时位数至少 $\lceil S/9\rceil$，位数少的一定更小，位数相同才逐位比较。

**四、三个高级变形。** ①双特征联立：数字和 $S$ 与交错和同时出现时，设奇位和 $O$、偶位和 $E$，则 $O+E=S$、$O-E$ 是 $11$ 的倍数；两式联立后 $O$、$E$ 只剩两三种可能，分类即可。②最大与最小之差：同一约束下做两次方向相反的贪心，最小值常出现"首位取到最小后，末两位这一类不可行，必须回退"的情形。③数字不重复型：数字集合固定时数字和是常数，交错和条件退化为"奇位和只能取某两个值"，再高位贪心；每步用"剩余数字之和"检验可行性，最后补唯一性说明。

**五、竞赛视角。** 看到"被 45、36、72、44 整除"配"最大/最小"，立刻拆互质因数；看到"数字和"，先写成等式；看到"最大与最小之差"，准备做两遍贪心；看到"1～9 各用一次"，先写总和 $45$，再用交错和锁定奇偶位和。容易混的是：$45$ 与 $9$、$36$ 与 $4$、$11$ 与 $99$（$99$ 要两条特征同时用）；还有"被 $5$ 整除"与"末位是 $5$"——别忘了 $0$。

**六、易错点（错误 → 正确 → 原因）。**
1. 只看数字和是 $9$ 的倍数就断定被 $45$ 整除 → 还要末位为 $0$ 或 $5$ → $45=5\times9$ 互质，两条缺一不可。
2. 认为被 $5$ 整除末位只能填 $5$ → $0$ 也合法，求最大时常是 $0$ 更大 → $0$ 是被 $5$ 整除的末位。
3. 把 $12$ 拆成 $2$ 与 $6$ 分别判断 → 拆成 $3$ 与 $4$ → $2$、$6$ 不互质，"分别"不等价于"整体"。
4. 求最大时首位取 $9$ 后随手填后面 → 每一位都要在"剩余和可行"下取最大，不可行就回退 → 高位大但后续不可行会整支作废。
5. 交错和只试 $0$ → 差还可能是 11、22 的正负倍数 → 差是 $11$ 的倍数，含负值与 $0$，且受位数个数限制。
6. 求最小只从首位试，不先定位数 → 先证位数下界，再逐位最小 → 位数少的一定更小。
7. 找到一个候选就结束 → 还要证明"没有更大（更小）的" → 极值题答案必须唯一，必须收口。

## 例题

### 例1：填入数字使五位数能被 72 整除并取最大（★★★★）
**题目**：在五位数 $\overline{8a4b6}$ 中填入数字 $a$、$b$，使它能被 $72$ 整除。这样的五位数中最大的是多少？

**覆盖点**：末三位锁定与数字和联立

**解析**：
为什么想到这一步：$72$ 既不是末位系也不是单纯的数字和系，必须拆。$72=8\times9$，且 $8$ 与 $9$ 互质，所以"被 $72$ 整除"等价于"末三位被 $8$ 整除"且"数字和被 $9$ 整除"。前一条只含 $b$，可以先把 $b$ 定死；后一条把 $a+b$ 限制成 $9$ 的倍数，候选就只剩几个。

第一步，锁 $b$：末三位是 $\overline{4b6}=406+10b$。逐个检查 $406,416,\dots,496$ 中的 $8$ 的倍数，得 $b=1,5,9$。（也可算 $406\div8$ 余 $6$，由 $6+10b\equiv0\pmod 8$ 得 $2b\equiv2\pmod 8$，即 $b\equiv1\pmod4$。）

第二步，用数字和：$8+a+4+b+6=18+a+b$ 是 $9$ 的倍数，而 $18+a+b$ 在 $18\sim36$ 之间，故 $a+b=0,9,18$；$a+b=0$ 与 $b\ge1$ 矛盾，舍去。

第三步，枚举候选：$b=1$ 时 $a=8$，得 $88416$；$b=5$ 时 $a=4$，得 $84456$；$b=9$ 时 $a=0$ 或 $9$，得 $80496$、$89496$。

第四步，比较：四个数的首位都是 $8$，比百位，$9>8>4>0$，最大是 $89496$；同前缀下已无其他 $b$ 可取，候选也就这四个。

第五步，验算：$8+9+4+9+6=36$ 是 $9$ 的倍数；末三位 $496=8\times62$；$89496\div72=1243$，整除。

**答案**：$89496$

### 例2：数字和为 20 的四位数中最大与最小之差（★★★★★）
**题目**：一个四位数的各位数字之和为 $20$，且能被 $4$ 整除。这样的四位数中，最大数与最小数相差多少？

**覆盖点**：数字和定值下的双向逐位贪心

**解析**：
为什么想到这一步：和固定为 $20$，"最大"与"最小"就是同一组约束下做两次方向相反的逐位贪心；$4$ 的倍数只看末两位，所以末两位是最后一道闸门，前面每一位都要为它留出可行空间。

求最大：千位取 $9$，百位取 $9$，则十位与个位之和为 $2$，即末两位只能是 $20$、$11$、$02$。其中只有 $20$ 是 $4$ 的倍数，得 $9920$。

求最小：千位取 $1$。百位取 $0$ 时十位与个位之和为 $19$，超过 $9+9=18$，不可能；百位取 $1$ 时和为 $18$，只能是 $99$，而 $99$ 不是 $4$ 的倍数；百位取 $2$ 时和为 $17$，末两位只能是 $98$ 或 $89$，都不是 $4$ 的倍数；百位取 $3$ 时和为 $16$，末两位试 $97$、$88$、$79$，只有 $88$ 是 $4$ 的倍数，得 $1388$。因此最小的四位数是 $1388$（百位再小都已被逐一排除）。

求差：$9920-1388=8532$。

验算：$9+9+2+0=20$ 且 $9920\div4=2480$；$1+3+8+8=20$ 且 $1388\div4=347$；两数都能被 $4$ 整除，数字和均为 $20$，故差为 $8532$。

**答案**：$8532$

### 例3：能被 44 整除且数字和为 20 的最大五位数（★★★★★★）
**题目**：一个五位数的各位数字之和为 $20$，且能被 $44$ 整除。这样的五位数中最大的是多少？

**覆盖点**：末两位与交错和的联合锁定

**解析**：
为什么想到这一步：$44=4\times11$，$4$ 与 $11$ 互质，必须两条特征同时用——$4$ 管末两位，$11$ 管奇偶位和的差。数字和 $20$ 又与奇偶位和直接相关，于是设奇位和 $O=a+c+e$、偶位和 $E=b+d$，用 $O+E=20$ 把交错和条件变成只含一个未知量的方程。

第一步，定 $O$、$E$：$O-E=20-2E$ 是偶数，故只能取 $0$ 或 $\pm22$（$\pm11$ 是奇数，被奇偶性排除）；而 $\pm22$ 会推出 $E=21$ 或 $E=-1$，都不可能是两位数字之和，故 $O-E=0$，即 $a+c+e=10$，$b+d=10$。

第二步，高位贪心：千位取 $9$，则 $c+e=1$，$b+d=10$。先试 $b=9$、$d=1$：$c+e=1$ 的填法只有 $c=1,e=0$（得 $99110$）与 $c=0,e=1$（得 $99011$），末两位 $10$、$11$ 都不是 $4$ 的倍数，这一支作废，必须回退。

第三步，回退一位：$b=8$、$d=2$，$c+e=1$ 得 $98120$ 与 $98021$，末两位 $20$ 是 $4$ 的倍数，$21$ 不是，取 $98120$。由于 $b=9$ 无解，$b\le8$，而 $b=8$ 已可行，故最大为 $98120$。

第四步，验算：$9+8+1+2+0=20$；$98120\div4=24530$；奇位和 $9+1+0=10$，偶位和 $8+2=10$，差为 $0$ 是 $11$ 的倍数，$98120\div11=8920$；$98120\div44=2230$，整除。

**答案**：$98120$

### 例4：用 1~9 各一次组成被 11 整除的最大九位数（★★★★★★★）
**题目**：用数字 $1,2,3,\dots,9$ 各一次组成九位数，使它能被 $11$ 整除。这样的九位数中最大的是多少？

**覆盖点**：全排列分类与极值唯一性证明

**解析**：
为什么想到这一步：数字集合固定，九个数字之和恒为 $45$，这是"不变量"；而 $11$ 的交错和只看奇位和与偶位和之差。于是先用 $45$ 把 $O$（五个奇位数字之和）、$E$（四个偶位数字之和）的可能值锁死，再在高位上逐位贪心，每一步都用"剩余数字之和"检验可行性。

第一步，锁定 $O$、$E$：$O+E=45$，$O-E$ 是 $11$ 的倍数。$O$ 是五个数字之和（$15\le O\le35$），$E$ 是四个数字之和（$10\le E\le30$），故 $O-E$ 只能是 $\pm11$（若为 $\pm33$，会推出 $O=39$ 或 $O=6$，超出范围）。所以 $(O,E)=(28,17)$ 或 $(17,28)$。

第二步，首位取 $9$：若取 $(17,28)$ 这一支，$9$ 在奇位上时，其余四个奇位数字之和只有 $8$，而四个不同正整数的和至少 $1+2+3+4=10>8$，矛盾。故 $9$ 只能落在 $O=28$ 这一支：$O=28$，$E=17$。

第三步，逐位贪心，每步验证剩余和可行：
- 第二位取 $8$：偶位还剩 $17-8=9$（$3$ 个数），奇位还剩 $28-9=19$（$4$ 个数），可行；
- 第三位取 $7$：奇位还剩 $12$（$3$ 个数），偶位仍 $9$（$3$ 个数），可行（如 $12=3+4+5$，$9=1+2+6$）；
- 第四位取 $6$：偶位剩 $3$（$2$ 个数），只能 $1+2$；奇位剩 $12$（$3$ 个数），只能 $3+4+5$，可行；
- 第五位取 $5$：奇位剩 $7$（$2$ 个数），只能 $3+4$；偶位剩 $3$，只能 $1+2$，可行；
- 第六位取 $2$（偶位两数和为 $3$，只能是 $2$ 与 $1$）；第七位取 $4$，第八位取 $1$，第九位取 $3$。

得 $987652413$。

第四步，收口说明唯一性：首位 $9$、第二位 $8$、第三位 $7$、第四位 $6$ 都是在"该前缀仍可满足 $O=28$、$E=17$"的前提下能取的最大数字（取小一位数立即变小）；后四位由剩余和唯一确定，故没有更大的。

第五步，验算：数字和 $9+8+7+6+5+2+4+1+3=45$；奇位和 $9+7+5+4+3=28$，偶位和 $8+6+2+1=17$，差 $28-17=11$，被 $11$ 整除；$987652413\div11=89786583$，整除。

**答案**：$987652413$
