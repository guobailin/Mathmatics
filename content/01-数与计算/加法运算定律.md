## 讲解

**加法交换律**：两个数相加，交换位置，和不变。
$$a + b = b + a$$

**加法结合律**：三个数相加，先把前两个数相加，或先把后两个数相加，和不变。
$$(a + b) + c = a + (b + c)$$

**减法的性质**（常配合用）：一个数连续减去两个数，等于减去这两个数的和：
$$a - b - c = a - (b + c)$$

**凑整思想**：观察哪些数能凑成整十、整百（如 25 与 75、136 与 64），用交换律、结合律把它们先加，让计算变简单。

## 例题

### 例1：交换律与结合律
**题目**：简便计算 $138 + 67 + 62 + 33$。

**覆盖点**：加法交换律, 加法结合律, 凑整简算

**解析**：138 与 62 凑 200，67 与 33 凑 100。原式 $= (138 + 62) + (67 + 33) = 200 + 100 = 300$。

**答案**：300

### 例2：减法性质
**题目**：简便计算 $456 - 178 - 122$。

**覆盖点**：凑整简算

**解析**：178 与 122 凑 300。原式 $= 456 - (178 + 122) = 456 - 300 = 156$。

**答案**：156
