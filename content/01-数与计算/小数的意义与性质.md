## 讲解

**意义**：分母是 10、100、1000……的分数可以用小数表示。十分之几是一位小数，百分之几是两位小数，千分之几是三位小数。

**小数数位**：小数点右边依次是十分位（0.1）、百分位（0.01）、千分位（0.001）……相邻进率仍是 10。

**小数的基本性质**：小数的**末尾**添上 0 或去掉 0，小数的大小不变。如 $0.5 = 0.50 = 0.500$。

**大小比较**：先比整数部分，整数部分大的数大；整数部分相同，从十分位起依次比较。

**易错点**：$0.5$ 和 $0.50$ **大小相等**但**计数单位不同**（0.1 与 0.01），精确程度不同；只有**末尾**的 0 才能去掉，$2.03$ 中间的 0 不能去。

## 例题

### 例1：小数的意义与组成
**题目**：0.375 中的 3、7、5 各表示什么？0.375 里面有多少个 0.001？

**覆盖点**：小数意义与数位

**解析**：3 在十分位表示 3 个 0.1，7 在百分位表示 7 个 0.01，5 在千分位表示 5 个 0.001。$0.375 = 375$ 个 0.001。

**答案**：3 个 0.1、7 个 0.01、5 个 0.001；375 个 0.001

### 例2：性质与比较
**题目**：① 化简 3.0600；② 把 0.9 改写成三位小数；③ 比较 0.89 和 0.9 的大小。

**覆盖点**：小数性质, 小数大小比较

**解析**：① 去掉末尾两个 0 得 3.06。② 末尾添两个 0 得 0.900。③ 整数部分相同，十分位 8 < 9，所以 0.89 < 0.9。

**答案**：① 3.06；② 0.900；③ 0.89 < 0.9
