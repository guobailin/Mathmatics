## 讲解

**一、负数的意义**

生活中常有意义相反的一对量：零上 5℃ 与零下 5℃，存入 200 元与取出 200 元，高于海平面 300 米与低于海平面 300 米。为了把这种相反意义的量表示出来，人们规定其中一种意义为正，与它相反的意义就为负。

像 $+5$、$3$、$1.5$ 这样的数叫正数；像 $-5$、$-3$、$-1.5$ 这样的数叫负数。正数前面的“$+$”可以省略，写成 5 仍是正数；负数前面的“$-$”不能省略，省略后就成了正数。带“$-$”的数读作“负几”，如 $-1.5$ 读作负一点五。

$0$ 既不是正数，也不是负数，它是正数与负数的分界。0℃ 是一个确定的温度，不能说“0℃ 没有温度”。

**二、在直线上表示正负数（数轴）**

画一条直线，任取一点表示 $0$（原点），规定向右为正方向，再选一段长度作单位长度。正数在 0 的右边，负数在 0 的左边，每个数都能在直线上找到唯一一点与它对应。例如 $-2.5$ 在 0 左边 2.5 个单位处，$+3$ 在 0 右边 3 个单位处。在直线上向右移动，数就变大；向左移动，数就变小。

**三、正负数的大小比较**

直线上的点，右边的总比左边的大。由此得三条规则：正数都大于 0，负数都小于 0，即“正数 $>$ 0 $>$ 负数”；两个负数比大小，离 0 越远的反而越小，如 $-8<-3$；正数与负数比，正数大。比较几个数时，先在直线上找到它们的位置，位置越靠右数越大。

**识别信号**：看到“零上/零下”“收入/支出”“盈利/亏损”“高于/低于海平面”“上升/下降”“向东/向西”，就用正负数表示相反意义的量；看到“在直线上表示”“距 0 几个单位”，就用数轴定位；看到“最低/最高/从低到高”，就先分正负，再比离 0 的远近。

**易错点**：

1. 把 0 当成正数（或负数）。正确：0 既不是正数也不是负数，它是分界点，比任何负数大、比任何正数小。
2. 比负数时按数字大小比，认为 $-8>-3$。正确：负数离 0 越远越小，所以 $-8<-3$。
3. 表示相反意义的量时标准不统一，前面规定向东为正，后面又说向西为正。同一题中“正”的方向只能规定一次。
4. 写负数时漏掉“$-$”号，把“支出 150 元”记成 $150$ 元。正确：记作 $-150$ 元，符号不能省。
5. 认为 0℃ 就是“没有温度”，或认为 0 米就是“没有高度”。正确：0 是一个确定的量，只是选作分界的标准。

## 例题

### 例1：用正负数表示相反意义的量（★★★）

**题目**：
（1）某天哈尔滨的气温是零下 $5$℃，记作多少摄氏度？
（2）妈妈存入银行 $200$ 元记作 $+200$ 元，那么取出 $150$ 元应记作多少元？
（3）一艘潜水艇在海平面以下 $120$ 米处，若海平面以上 $300$ 米记作 $+300$ 米，那么它的位置应记作多少米？

**覆盖点**：正负数的意义与读写

**解析**：
第一步，找出每题中意义相反的那一对量：“零上”与“零下”、“存入”与“取出”、“海平面以上”与“海平面以下”。

第二步，看题目已经把哪种意义定为正。第（1）题以零上为正，零下 $5$℃ 就与正相反，记作 $-5$℃；第（2）题以存入为正，取出与存入相反，$150$ 元记作 $-150$ 元；第（3）题以海平面以上为正，海平面以下 $120$ 米记作 $-120$ 米。

第三步，检查符号：三个结果都表示“相反的那一种意义”，都带“$-$”号，且“$-$”号不能省略。

**验算**：把结果读回生活语言——$-5$℃ 比 0℃ 低 $5$℃，与“零下 5 摄氏度”一致；$-150$ 元表示支出 $150$ 元，与“取出 150 元”一致；$-120$ 米表示低于海平面 $120$ 米，与题意一致。符号与题意方向全部相符。

**答案**：$-5$℃；$-150$ 元；$-120$ 米。

### 例2：数轴上的距离与移动（★★★★）

**题目**：在数轴上，点 A 表示 $-4$，点 B 表示 $+6$。
（1）A、B 两点相距多少个单位长度？
（2）一只小虫从点 A 出发，沿数轴向右爬行 $9$ 个单位长度到达点 C，点 C 表示什么数？
（3）点 C 在点 B 的左边还是右边？

**覆盖点**：在数轴上表示正负数

**解析**：
第一步，画图定位。以 0 为分界，点 A 在 0 左边 $4$ 个单位处，点 B 在 0 右边 $6$ 个单位处。

第二步，求距离。从 A 向右数到 0 要 $4$ 个单位，从 0 再向右数到 B 要 $6$ 个单位，两段合起来就是两点间的距离：$4+6=10$（个单位长度）。

第三步，求点 C。小虫从 $-4$ 向右爬 $9$ 个单位：先向右 $4$ 个单位到 0，还剩 $9-4=5$ 个单位，继续向右 $5$ 个单位到 0 右边第 $5$ 个点，所以点 C 表示 $+5$。

第四步，定位置。$+5$ 在 0 右边 $5$ 个单位处，$+6$ 在 0 右边 $6$ 个单位处，$5<6$，所以点 C 在点 B 的左边。

**验算**：从 $-4$ 到 $+5$，向右共移动 $4+5=9$ 个单位，与题中“爬行 9 个单位”相符；$+5$ 与 $+6$ 都在 0 右边，$+5$ 离 0 更近，必在 $+6$ 左边。若把点 C 写成 $-13$，则是向左移动的结果，方向错了。

**答案**：相距 $10$ 个单位长度；点 C 表示 $+5$；点 C 在点 B 的左边。

### 例3：一天中气温的变化与比较（★★★★★）

**题目**：某地一天中三个时刻的气温如下：8 时是 $-3$℃，14 时是 $4$℃，20 时是 $-1$℃。
（1）把三个时刻的气温按从低到高排列；
（2）这三个时刻中，哪一段时间气温变化最大？变化了多少摄氏度？
（3）若从 20 时起气温继续下降 $6$℃，那么次日凌晨的气温是多少摄氏度？

**覆盖点**：正负数的大小比较

**解析**：
第一步，比较大小。三个数中只有 $4$ 是正数，最大；$-3$ 和 $-1$ 都是负数，$-3$ 离 0 有 $3$ 个单位，$-1$ 离 0 只有 $1$ 个单位，离 0 远的反而小，所以 $-3<-1$。从低到高排列为 $-3℃<-1℃<4℃$。

第二步，算气温变化。变化多少摄氏度，就是两个时刻在数轴上的距离：8 时到 14 时，从 $-3$ 到 $4$，先向右 $3$ 个单位到 0，再向右 $4$ 个单位到 $4$，共 $3+4=7$（℃）；14 时到 20 时，从 $4$ 到 $-1$，先向左 $4$ 个单位到 0，再向左 $1$ 个单位到 $-1$，共 $4+1=5$（℃）。$7>5$，所以 8 时到 14 时气温变化最大，变化了 $7$℃。

第三步，求凌晨气温。下降就是在数轴上向左移动，$-1$ 已经在 0 左边 $1$ 个单位，再向左移动 $6$ 个单位，就一共在 0 左边 $1+6=7$ 个单位，所以气温是 $-7$℃。

**验算**：把 $-3$ 向右移 $7$ 个单位得 $4$，与 14 时气温相符；把 $4$ 向左移 $5$ 个单位得 $-1$，与 20 时气温相符；把 $-1$ 向左移 $6$ 个单位得 $-7$。再由小到大检查：$-7<-3<-1<4$，凌晨最冷、14 时最暖，符合一天中气温变化的常理。

**答案**：$-3℃<-1℃<4℃$；8 时到 14 时变化最大，变化了 $7$℃；次日凌晨的气温是 $-7$℃。
