## 讲解

**读法**：先分级（四位一级），从最高级读起。亿级、万级的数按个级的读法读，读完加上"亿"或"万"。

**零的读法**：每级**末尾**的 0 都不读；每级**中间或开头**有一个 0 或连续几个 0，都只读一个"零"。

**写法**：从最高级写起，哪个数位上一个单位也没有，就在那个数位上写 0 占位。

**检验方法**：写完后再读一遍，与原题对照；或分级数位数。

**易错点**：如 30050600 读作"三千零五万零六百"——万级中间的两个 0 只读一个，个级开头的 0 要读；写"五亿零四十万"时，千万位、百万位等空位都要补 0，共写成 500400000。

## 例题

### 例1：读出大数
**题目**：读出下列各数：40600000、70005080、300400500。

**覆盖点**：大数读法, 零的读写规则

**解析**：40600000 分级为 4060┆0000，读作四千零六十万（个级全是 0，不读）。70005080 分级为 7000┆5080，万级末尾 0 不读，读作七千万五千零八十。300400500 分级为 3┆0040┆0500，读作三亿零四十万零五百。

**答案**：四千零六十万；七千万五千零八十；三亿零四十万零五百

### 例2：写出大数
**题目**：写出下列各数：六亿零七十万三千、八千万零九。

**覆盖点**：大数写法

**解析**：六亿零七十万三千：亿级 6，万级 0070，个级 3000，写作 600703000。八千万零九：亿级无，万级 8000，个级 0009，写作 80000009。

**答案**：600703000；80000009
