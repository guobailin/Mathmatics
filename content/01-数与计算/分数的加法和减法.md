## 讲解

**同分母分数加减**：分母不变，分子相加减，结果能约分的要约分。
$$\frac{3}{7} + \frac{2}{7} = \frac{5}{7}$$

**异分母分数加减**：先**通分**化成同分母，再加减。
$$\frac{1}{4} + \frac{1}{6} = \frac{3}{12} + \frac{2}{12} = \frac{5}{12}$$

**带分数加减**：整数部分与分数部分分别相加减；分数部分不够减时，从整数部分退 1 化成假分数再减。

**简便计算**：整数加法的交换律、结合律对分数同样适用，同分母的先结合，如 $\frac{5}{9} + \frac{2}{3} + \frac{4}{9}$。

**易错点**：异分母分数**不能直接**分子加分子、分母加分母；得数要约成最简分数。

## 例题

### 例1：异分母加减
**题目**：计算 $\dfrac{3}{4} - \dfrac{1}{6}$ 和 $\dfrac{5}{8} + \dfrac{1}{6}$。

**覆盖点**：异分母加减

**解析**：$\frac{3}{4} - \frac{1}{6} = \frac{9}{12} - \frac{2}{12} = \frac{7}{12}$。$\frac{5}{8} + \frac{1}{6} = \frac{15}{24} + \frac{4}{24} = \frac{19}{24}$。

**答案**：$\dfrac{7}{12}$；$\dfrac{19}{24}$

### 例2：带分数减法与简算
**题目**：① 计算 $3\dfrac{1}{4} - 1\dfrac{3}{4}$；② 简便计算 $\dfrac{5}{7} + \dfrac{5}{9} + \dfrac{2}{7}$。

**覆盖点**：同分母加减, 分数加减简算

**解析**：① 分数部分 $\frac{1}{4}$ 不够减 $\frac{3}{4}$，从整数 3 退 1 得 $2\frac{5}{4} - 1\frac{3}{4} = 1\frac{2}{4} = 1\frac{1}{2}$。② 同分母先结合：$\frac{5}{7} + \frac{2}{7} + \frac{5}{9} = 1 + \frac{5}{9} = 1\frac{5}{9}$。

**答案**：① $1\dfrac{1}{2}$；② $1\dfrac{5}{9}$
