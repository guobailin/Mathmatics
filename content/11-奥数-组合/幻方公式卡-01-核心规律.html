幻方公式卡 01｜核心规律

定义 · 幻和 · 中心 · 对称

1. 幻方与幻和

把互不重复的数填入 n×n 方格，使每行、每列、两条主对角线的和都相等；这个公共和叫幻和 M。

若填入连续整数 1,2,…,n²：

M = n(n² + 1) / 2

推导：总和 T = n²(n²+1)/2；又 n 行合计为 nM，因此 nM=T。

例：三阶 M=15；四阶 M=34；五阶 M=65；六阶 M=111；七阶 M=175。

2. 三阶中心数：重数法（变量图解）

中行、中列、两条对角线共四条线，每条和为 M。图中中心格记作 c；四条线相加时，其他格各算一次，中心 c 算四次，多算 3 次：

4M = T + 3c

而 T=3M，所以：

M = 3c　　c = M/3

对 1～9：T=45，M=15，中心 c=5（也是九个数的平均数）。

3. 中心对称互补

三阶幻方中，中心两侧的相对两格与中心在同一直线上：

x + c + y = M
x + y = M − c = 2c

因此：

a+i = b+h = c+g = d+f = 2m

标准 1～9 三阶幻方中 m=5，所以四组相对数之和均为10。

4. 奇偶、对称与线性变换

奇偶性：1～9标准三阶幻方中，中心5；四角为偶数；四边中格为奇数。此结论不能推广到任意数字集合。

旋转与镜像：一个三阶基本幻方可旋转、翻转得到8种方向形式（正方形的 D₄ 对称）。

仿射变换：若每格 x 变为 x′=ax+b，则每条三格线的新和为：

M′ = aM + 3b

标准 1～9 幻方 M=15，因此 M′=15a+3b。要求 a≠0 才保持数字互不相同。

先求幻和，再看中心；相对两格互补，等于中心数的 2 倍。
