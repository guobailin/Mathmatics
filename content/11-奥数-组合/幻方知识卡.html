一、幻和公式（先算幻和）

每行、每列、两条对角线的和都相等，这个和叫 幻和 S。

S = n(n² + 1) ÷ 2　（填 1, 2, …, n²）

n 行把 n² 个数各数一遍，故 nS = 1 + 2 + … + n² = n²(n²+1)÷2。

常用：三阶 15、四阶 34、五阶 65、六阶 111、七阶 175。

等差填数（n² 个数，中位数 m）：S = n × m；三阶即 S = 3m。

二、三阶核心规律

① 中心 = S ÷ 3 = 九数平均数；1～9 时中心 5、幻和 15。

a + i = b + h = c + g = d + f = 2e
按 a b c / d e f / g h i 排列，e 为中心

② 对称两格之和 = 2 × 中心（1～9 时 = 10）。

③ 1～9 标准：四角为偶数、边中为奇数。
三阶本质一种，旋转、镜像共 8 种。

④ 角格 = 与它不同行不同列的两个边格的平均数，如 (7+9)÷2 = 8。

⑤ 先排雷：九数须配成四对等和（每对 = 2×中心），剩下那个数即中心；配不成即无解。

⑥ 易错：九数总和不是幻和；对称两格之和是 2×中心，不是幻和。

三、构造与判定

① 罗伯法口诀（奇数阶）：1 居上行正中央，依次斜填切莫忘；上出框时往下填，右出框时左边放；排重便在下格填，右上排重一个样。

② 四阶：先顺填 1～16，再把两条对角线上的 x 换成 17 − x；互补对和都是 17，幻和 34。

③ 二阶不存在：a + b = a + c ⇒ b = c，与“数字不重复”矛盾。

④ 比较法：两式等和相减，消去公共格；如左中 + 上中 = 2 × 右下。

⑤ 两条对角线之和 = 2S − 中心（中心算了两遍，扣掉）。

⑥ 缩放平移：每格 ×a 再加 b，新幻和 = aS + nb（三阶 15a + 3b）。

⑦ 奇数阶用罗伯法、双偶数阶用互补数对、单偶数阶用分区交换。

四、例5：5×5 等和方格怎么做

① 定目标：主对角线 2+7+8+2+7=26，故每条线之和为 26。

② 行中求数：第二行末格=26−(3+7+8+2)=6；第三行首格=26−(3+8+4+6)=5；第四行中格=26−(8+4+2+3)=9。

③ 列中求数：第一列末格=8；第五行第二格=3；第四列首格=10。

④ 收尾：第一行末格=4，再逐行、逐列、逐对角线验算。
