# content/ 内容目录

小学数学知识库的唯一数据源。每个模块一个目录，每个知识点一个 Markdown 文件。

## 新增知识点

```bash
cp ../templates/knowledge-point.md "08-奥数-数论/新知识点.md"
# 编辑元数据、讲解、例题（例题必须标注 **覆盖点**）
python3 ../tools/build.py
```

## 规则

1. `id` 全局唯一，用模块英文缩写 + 短横线命名，一经发布不要修改（检索与关联引用都依赖它）。
2. `module` 必须与所在目录名去掉序号前缀后一致（如目录 `08-奥数-数论` → `module: 奥数-数论`）。
3. `skills` 列出本知识点的全部子技能；每道例题的 `**覆盖点**` 必须取自该清单，且清单中每一项至少被一道例题覆盖。
4. 例题数量默认 2–4 道，按难度阶梯排列；能一题覆盖多个子技能就不拆成两题。奥数专题建议 4 道，按竞赛难度 ★4–★7 排列。
5. 图片放 `assets/`，用 `![说明](/assets/xxx.svg)` 引用，优先 SVG。
6. 公式用 LaTeX：行内 `$...$`，独立行 `$$...$$`。
7. 新增知识点必须挂入 `curriculum.yaml` 的对应年级/领域（`content:` 填知识点 id）；`content: null` 表示大纲已列入、内容待补充。`tools/build.py` 会校验每个知识点都已挂入大纲。
