## 讲解

**分类列举**（也叫分类枚举）是解决“一共有多少种”最朴素、也最可靠的办法：把所有符合条件的情况，按**同一个标准**切成几块，每块内部按**固定顺序**一个一个写出来，最后把各块的数量相加：

$$N=n_1+n_2+\cdots+n_k$$

用这个式子必须同时做到两件事。**不重**：任意两类没有共同的情况；**不漏**：所有类合起来正好是全部情况。做到这两点，答案一定正确；做不到，数得再快也是错的。

**怎样选分类标准。** 好的标准有三个特点：一看就知道每个情况该归到哪一类；每一类都容易数（常常退化成简单列举或一步乘法）；类数不太多。常见标准有四类：按某个数位的取值分（百位是 $1,2,3$……）、按数量分（$5$ 角硬币用 $0,1,2$ 枚）、按位置分（$0$ 出现在个位、十位、百位）、按大小关系分（$a<b$、$a=b$、$a>b$）。标准一旦选定，整道题只用它一个。

**块内要有序。** 每一类里再规定列举顺序，比如“从小到大”“从高位到低位”“$a$ 固定、$b$ 递增”。顺序固定后，写到哪儿、下一个该写什么就都清楚了。列举时把情况真的写出来（如 $113,\ 122,\ 131$），比只在心里数安全得多。

**识别信号。** 题目问“有多少种”“共有几种”，条件里带“至少”“不超过”“互不相同”“不含某个数字”，而总数不大、现成公式套不上时，就该分类列举。动手分四步：**定标准 → 定顺序 → 逐类列全 → 换路验算**。第四步最容易被跳过：换个标准再数一遍，或用“总数减去不合要求的”，两个结果对上才算做完。

### 易错点

1. **错误做法**：一题里混用两个标准，比如一半按位数分、一半按“含不含 $0$”分。**正确做法**：一次只用**一个**标准切分，切完检查两类有没有公共情况、合起来是不是全部。
2. **错误做法**：类内想到哪种写哪种，写完直接数个数，结果漏算或重复。**正确做法**：先写下顺序（如“$a$ 从小到大，$b$ 从 $a+1$ 到 $9$”），照顺序写并逐个编号，最后看首尾有没有跳号。
3. **错误做法**：把边界条件算错，比如“每人至少 $2$ 本”却把 $1$ 本的情况也列进去，或漏掉“最多”的边界。**正确做法**：先把每个量允许的范围写成不等式（如 $2\le a\le 7$），每类都对照范围检查。
4. **错误做法**：同一个对象被数了两遍，比如一个数里有两个 $0$ 时，按数位分类又把整个数当作一次。**正确做法**：按数位分类时，每一位只负责自己那一位，最后相加；再用“按数”的方式复核一次。

## 例题

### 例1：把本子分给两人（★★★）
**题目**：把 $9$ 本相同的笔记本分给甲、乙两人，每人至少分到 $2$ 本，一共有多少种不同的分法？

**覆盖点**：分类标准

**解析**：两人的本数之和固定是 $9$，所以只要确定甲得几本，乙得的本数就唯一确定。于是按“甲得到的本数”分类，这正是本题最省事的标准。

甲最少 $2$ 本；乙也至少 $2$ 本，所以甲最多 $9-2=7$ 本，即甲的本数只能取 $2,3,4,5,6,7$。

逐类列举（写成“甲—乙”）：

- 甲 $2$ 本：$2-7$，$1$ 种；
- 甲 $3$ 本：$3-6$，$1$ 种；
- 甲 $4$ 本：$4-5$，$1$ 种；
- 甲 $5$ 本：$5-4$，$1$ 种；
- 甲 $6$ 本：$6-3$，$1$ 种；
- 甲 $7$ 本：$7-2$，$1$ 种。

六类中甲的本数各不相同，互不重叠；甲的本数取遍 $2\sim7$ 时已包含全部可能，故不漏。所以

$$N=1+1+1+1+1+1=6$$

**验算**：先放开“至少 $2$ 本”，只要求每人至少 $1$ 本，则甲可取 $1\sim8$，共 $8$ 种；其中甲得 $1$ 本（$1-8$）和乙得 $1$ 本（$8-1$）这两种不合要求，$8-2=6$，与列举结果一致。

**答案**：$6$ 种。

### 例2：两数之和大于10（★★★★）
**题目**：从 $1,2,3,\cdots,9$ 这九个数中选出两个不同的数，使它们的和大于 $10$，一共有多少种不同的选法？

**覆盖点**：有序枚举

**解析**：选法不计顺序，先规定 $a<b$，这样每种选法只写一次，避免 $a+b$ 与 $b+a$ 重复。再按 $a$ 从小到大分类，每类中 $b$ 从 $a+1$ 递增到 $9$，逐个检验 $a+b>10$。

- $a=1$：$b\le9$，$1+b\le10$，没有符合的，$0$ 种；
- $a=2$：只有 $b=9$，$2+9=11>10$，$1$ 种；
- $a=3$：$b=8,9$，$3+8=11,\ 3+9=12$，$2$ 种；
- $a=4$：$b=7,8,9$，和分别为 $11,12,13$，$3$ 种；
- $a=5$：$b=6,7,8,9$，和分别为 $11,12,13,14$，$4$ 种；
- $a=6$：因 $b>a=6$，$b$ 从 $7$ 起取 $7,8,9$，和 $13,14,15$，$3$ 种；
- $a=7$：$b=8,9$，和 $15,16$，$2$ 种；
- $a=8$：$b=9$，和 $17$，$1$ 种；
- $a=9$：没有更大的 $b$，$0$ 种。

各类的 $a$ 不同，互不重叠；$a$ 从 $1$ 到 $9$ 一个不落，故不漏。合计

$$N=0+1+2+3+4+3+2+1+0=16$$

**验算**：用“总数减去不合要求的”。九个数中任取两个不同数共有 $9\times8\div2=36$ 种；和不超过 $10$ 的选法按和分类：和为 $3,4,5,6,7,8,9,10$ 时分别有 $1,1,2,2,3,3,4,4$ 种，共 $20$ 种。于是 $36-20=16$，与上面一致。

**答案**：$16$ 种。

### 例3：1到200里有多少个数字0（★★★★★）
**题目**：把 $1$ 到 $200$ 这 $200$ 个整数依次写出来，一共写了多少个数字 $0$？

**覆盖点**：不重不漏校验

**解析**：把“$0$ 出现的位置”作为分类标准，个位、十位、百位各数一次。同一个 $0$ 只属于一个数位，这样分类天然不重；三个数位合起来就是全部，故不漏。

- **个位是 $0$**：$10,20,30,\cdots,200$，每 $10$ 个数出现一次，共 $200\div10=20$ 个。
- **十位是 $0$**：两位数的十位不可能是 $0$；$100\sim109$ 有 $10$ 个，再加上 $200$ 这 $1$ 个，共 $10+1=11$ 个。
- **百位是 $0$**：三位数最高位不能是 $0$，一位数、两位数也不写前导 $0$，所以 $0$ 个。

所以

$$N=20+11+0=31$$

注意 $100$ 与 $200$ 各含两个 $0$，它们分别在个位、十位各被数到一次，并没有重复计数。

**验算**：换“按数”的标准复核。$1\sim200$ 中含 $0$ 的数有：$10,20,\cdots,90$ 共 $9$ 个；$100\sim109$ 共 $10$ 个；$110,120,\cdots,190$ 共 $9$ 个；$200$ 共 $1$ 个。合计 $9+10+9+1=29$ 个数。其中 $100$ 和 $200$ 各含两个 $0$，比“每个数算一个”多出 $2$ 个，故 $0$ 的总个数为 $29+2=31$，与按数位数的结果一致。

**答案**：$31$ 个。
