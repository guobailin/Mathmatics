## 讲解

**枚举法**（也叫穷举法）就是：题目问“有多少种”，我们不去套公式，而是把**所有可能的情况一个一个写出来**，再数一数。它看起来笨，却是最可靠的方法——只要做到**不重不漏**，答案一定对。

难点不在“列”，而在“列得清楚”。想把情况列全，靠两件工具：**分类**和**有序**。

**分类**：按同一个标准把全部情况切成互不重叠的几块，每块单独数，最后相加：

$$N=n_1+n_2+\cdots+n_k$$

用这个式子必须同时满足两条：**任意两类没有公共情况**（不重），**所有类合起来正好是全部情况**（不漏）。常见分类标准有：按首位数字分、按某个物品的个数分、按大小关系分、按是否含有某个数字分。

**有序**：在每一类内部，规定一个固定的列举顺序，比如“首位从小到大、第二位从小到大”，或者“从大到小”“按 $a\le b$ 排列”。顺序固定了，写到哪儿、下一个该写什么就都清楚了，不会漏也不会回头重复。

**树状图**是“有序”的图形版：第一步有几种画几条枝，每条枝上再长出第二步的可能，走到叶子就把一条完整的情况走完了。情况多、步骤多时，画树状图比硬想要稳妥得多。

### 识别信号与解题步骤

1. **看到“有多少种不同的……”“共有几种”**，而总数不大、条件比较杂：优先枚举。
2. **看到“不计顺序”“两人一样”**：枚举时要人为规定顺序（如只写 $a<b$），否则会把同一种数两遍。
3. **看到“每一步都有几种选择，且选择受前面影响”**：画树状图。

动手四步：**定标准 → 定顺序 → 逐类列全 → 换一条路验算**。第四步最容易被忽略，却最能救命：用乘法原理、用“总数减去不合要求的”，或换个分类标准再数一遍，两个结果对上才算完成。

### 易错点

1. **错误做法**：想到哪种写哪种，写完就数。**正确做法**：先写下分类标准和列举顺序（例如“按十位数字 1、2、3 依次列举”），再照着顺序写，写完回看有没有跳号。
2. **错误做法**：一题里混用两个分类标准，比如一半按“位数”分、一半按“含不含 0”分。**正确做法**：一次只用**一个**标准切分；切完检查“两类有没有公共情况”“合起来是不是全部”。
3. **错误做法**：把 $1+6$ 和 $6+1$ 当成两种。**正确做法**：题目说“不计顺序”时，规定 $a\le b$，只写一种；说“分别给两人”时才区分顺序。
4. **错误做法**：允许 0 放在首位、允许数字重复，或漏掉“恰好”“至少”这类边界。**正确做法**：把题目条件逐条抄在草稿上，每列一个就对照一遍，最后用总数核对。

## 例题

### 例1：用四个数字组两位数（★★★）
**题目**：用 $0,1,2,3$ 这四个数字组成**没有重复数字**的两位数，一共可以组成多少个？

**覆盖点**：有序枚举

**解析**：两位数的十位不能是 $0$，所以按十位数字分类，并在每类中按个位从小到大列举。

- 十位是 $1$：$10,\ 12,\ 13$，共 $3$ 个；
- 十位是 $2$：$20,\ 21,\ 23$，共 $3$ 个；
- 十位是 $3$：$30,\ 31,\ 32$，共 $3$ 个。

三类互不重叠，合起来就是全部，所以

$$N=3+3+3=9$$

**验算**：若不管“首位不能为 0”，四个数字排两个不同数字有 $4\times 3=12$ 个有序数对；其中 $01,\ 02,\ 03$ 这 $3$ 个不是两位数，$12-3=9$，与枚举结果一致。

**答案**：$9$ 个。

### 例2：硬币凑一角（★★★★）
**题目**：用 $1$ 分、$2$ 分、$5$ 分的硬币凑成 $1$ 角（即 $10$ 分），每种硬币都可以用任意多枚，一共有多少种不同的凑法？

**覆盖点**：分类枚举

**解析**：三种硬币里 $5$ 分面值最大，按“$5$ 分硬币用几枚”分类最省事，因为 $10\div 5=2$，$5$ 分硬币最多 $2$ 枚。

- 用 $2$ 枚 $5$ 分：已凑满 $10$ 分，只有 $1$ 种；
- 用 $1$ 枚 $5$ 分：剩 $5$ 分用 $1$ 分、$2$ 分凑，$2$ 分硬币可放 $0,1,2$ 枚，即 $5=5\times1$、$5=3\times1+2$、$5=1\times1+2\times2$，共 $3$ 种；
- 用 $0$ 枚 $5$ 分：$10$ 分用 $1$ 分、$2$ 分凑，$2$ 分硬币可放 $0,1,2,3,4,5$ 枚，共 $6$ 种。

三类互不重叠（$5$ 分硬币的枚数不同），合起来覆盖全部，故

$$N=1+3+6=10$$

**验算**：换一个标准——按 $2$ 分硬币的枚数数：$0$ 枚时有 $3$ 种（$10$ 个 $1$ 分、$1$ 个 $5$ 分 $+5$ 个 $1$ 分、$2$ 个 $5$ 分），$1$ 枚时 $2$ 种，$2$ 枚时 $2$ 种，$3,4,5$ 枚时各 $1$ 种，$3+2+2+1+1+1=10$，与上面一致。

**答案**：$10$ 种。

### 例3：三人传球回到起点（★★★★★）
**题目**：甲、乙、丙三人传球，从甲开始，每次把球传给另外两人中的一人。传 $4$ 次后球正好回到甲手中，共有多少种不同的传球方式？

**覆盖点**：树状图列举

**解析**：球第 $4$ 次传到甲，说明第 $3$ 次结束时球在乙或丙手中，且第 $4$ 次只能有一种传法。所以只需按前 $3$ 次画树状图，并在第 $3$ 次处剔除“球在甲手中”的枝。

按第 $1$ 次传给谁分成两支：

- 第 $1$ 次传给乙：
  - 第 $2$ 次传给甲，则第 $3$ 次可传乙或丙，$2$ 种；
  - 第 $2$ 次传给丙，则第 $3$ 次若传给甲，第 $4$ 次就回不到甲，只能传给乙，$1$ 种。

  共 $2+1=3$ 种。
- 第 $1$ 次传给丙：由对称性同样是 $3$ 种。

两支互不重叠，合计

$$N=3+3=6$$

把 $6$ 条路线写全验证：甲→乙→甲→乙→甲，甲→乙→甲→丙→甲，甲→乙→丙→乙→甲，甲→丙→甲→乙→甲，甲→丙→甲→丙→甲，甲→丙→乙→丙→甲，正好 $6$ 条。

**验算**：传 $4$ 次共有 $2^4=16$ 种传法。设第 $n$ 次后球在甲手中的方式数为 $a_n$，则 $a_0=1$，且第 $n+1$ 次回到甲的方式数等于“第 $n$ 次后球不在甲”的方式数，即 $a_{n+1}=2^{n}-a_n$。于是 $a_1=1-1=0$，$a_2=2-0=2$，$a_3=4-2=2$，$a_4=8-2=6$。再由对称性，球最终在乙、丙手中的方式各为 $(16-6)\div2=5$ 种，$6+5+5=16$，总数吻合。

**答案**：$6$ 种。
