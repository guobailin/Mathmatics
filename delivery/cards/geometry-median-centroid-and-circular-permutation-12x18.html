几何 · 三角形

中线定理与重心性质

一条中线看长度关系；三条中线看重心与面积关系
一、三角形中线定理（阿波罗尼斯定理）

若 D 是 BC 的中点，则 AD 是边 BC 上的中线，且：

AB² + AC² = 2(AD² + BD²)

因为 BD = DC = BC/2，也可写成：

AB² + AC² = 2AD² + ½BC²
理解：两腰平方和 = 2×（中线平方 + 半底边平方）。已知三边可求中线；已知中线也可反求边长关系。
二、三角形重心的性质
  • 三条中线交于一点，交点 G 叫重心。
  • 重心把每条中线分成 2∶1，靠顶点的一段较长。
  • 若 D 是 BC 中点，则 AG:GD = 2:1，且 AG = ⅔AD。
  • 三条中线把三角形分成 6 个面积相等的小三角形。
易错提醒：2∶1 的顺序是“顶点到重心 : 重心到边中点”；不要写反。中线是线段，重心是三条中线的交点。

计数原理 · 排列组合

圆排列公式

围成一圈：旋转后相同，镜像通常不同
一、核心公式

n 个不同元素围成一圈，若只把旋转后的排列视为相同：

圆排列数 = (n − 1)!

其中 n ≥ 2。常见圆桌问题 n ≥ 3。

二、为什么是 (n−1)!
  • 先固定一个人（或一个元素）的位置，消除整体旋转造成的重复。
  • 其余 n−1 个不同元素自由排列，共有 (n−1)! 种。
例：5 人围圆桌坐 → (5−1)! = 4! = 24 种
三、先判断“什么算相同”
圆桌就座只消旋转；顺时针与逆时针次序不同。用 (n−1)!
项链 / 手环若翻转后也视为相同，才需要进一步考虑镜像重复。
四、典型变式
  • 甲必须坐某位置：固定甲，其余人圆排列，(n−1)!。
  • 甲、乙相邻：把甲乙捆成一组，组内有 2 种次序；整体圆排列为 2×(n−2)!。
  • 甲、乙不相邻：总数 − 相邻数 = (n−1)! − 2(n−2)!。
易错提醒：不能直接用 n!；圆排列不是把镜像也自动合并。只有题目明确说“翻转后相同”时，才按项链/手环模型处理。
