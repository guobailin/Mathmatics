中线定理

阿波罗尼斯定理 · 三角形三边与中线之间的长度关系

一、中线定理阿波罗尼斯定理

在 △ABC 中，D 是 BC 的中点，AD 就是 BC 边上的中线，记 ma = AD；三边 a = BC，b = CA，c = AB。则三边与中线满足：

b2 + c2 = 2(ma2 + (a2)2) 等价写法：b2 + c2 = 2ma2 + a2/2（不用开根号，更容易计算）
推导：两式相加，消去 cos θ
设 ∠ADB = θ，则 ∠ADC = 180° − θ。分别在 △ABD、△ADC 中用余弦定理： c2 = ma2 + (a/2)2 − ma·a·cos θ b2 = ma2 + (a/2)2 + ma·a·cos θ 相加：b2 + c2 = 2ma2 + a2/2 = 2(ma2 + (a/2)2)
  • 已知三边求中线：ma = ½√2b2 + 2c2 − a2；已知两边和第三边上的中线，也可反求第三边。
  • 信号：看到「中线 + 两边平方和」就套定理；直角三角形斜边上的中线 = 斜边的一半（特例，可检验）。
例：a = 6，b = 5，c = 7 时，ma2 = (2×52 + 2×72 − 62)/4 = 28，ma = 2√7。验算：52 + 72 = 2(28 + 32) = 74。
记忆：两邻边平方和 = 2 ×（中线² + 半底边²）；括号外的 2 要乘进括号里的两项。

重心的性质与中线

三条中线交于一点 · 2∶1 分点 · 面积三等分

一、重心把中线分成 2∶1

三条中线交于一点 G，G 叫三角形的重心。重心在每条中线上都把线段分成 2∶1 的两部分：顶点到重心是 2 份，重心到对边中点是 1 份。

AG = 23ma　，　GM = 13ma ma = AM，M 为 BC 中点；AM 被 G 分成 2∶1

二、重心的主要性质

  • 比例换算：AG = 2GM，GM = ½AG，AM = 3GM，AG = ⅔AM。
  • 面积：S△ABG = S△BCG = S△CAG = ⅓S△ABC；三条中线分成的 6 个小三角形面积相等，每个 = 1⁄6S△ABC。
  • 坐标：G 是三个顶点坐标的平均点，G = ((xA+xB+xC)/3, (yA+yB+yC)/3)。
  • 联用中线定理：AG = ⅔ma = ⅓√2b2 + 2c2 − a2。
例：若中线 AM = 9，则 AG = 6，GM = 3；若 S△ABC = 12，则 S△ABG = 4。
易错：2∶1 的顺序是「顶点→重心 : 重心→中点」，写反即错；重心是三条中线的交点（三条高的交点是垂心，别混）。
识别信号：题目出现「中线交点」「面积相等」「2∶1」「顶点到重心」，任意一个出现，就往重心想。

圆排列公式

圆形选点：先消旋转重复，再除起点重复 · 基础圆排列 (n−1)!

一、间隔受限的圆排列秒杀公式

n 个均匀分布的点中任选 k 个，要求任意两点之间至少相隔 d 个间隔（即中间至少隔 d−1 个点），选法总数为：

nk × Ck−1n−k(d−1)−1 n 总点数 · k 选几个 · d 最小间隔数（d ≥ 2）· 前提 n ≥ kd

二、推导：环形间隔方程

  • 固定一个选中点，顺时针写 k 段间隔 gi：每段 ≥ d，总和 = n。
  • 令 hi = gi − d ≥ 0，则 h 总和为 n−kd，间隔组数 = Ck−1n−k(d−1)−1。
  • 每组被 k 个选中点各当过一次起点，起点共 n 个：总数 = (n/k) × 组合数。

三、例题：12 点选 3 点，弦长大于半径

  • 12 等分 → 相邻点间隔 30°；弦长 > 半径 ⇔ 圆心角 > 60° ⇔ 至少隔 3 个间隔，故 d = 3（隔 2 个间隔时圆心角恰为 60°，弦长等于半径，不满足）。
代入 n = 12，k = 3，d = 3：总数 = 123 × C3−112−3×(3−1)−1
= 4 × C25 = 4 × 10 = 40

四、特例与易错

  • 不相邻特例（d = 2）：nk × Ck−1n−k−1 = nn−k × Ckn−k。
  • d 数的是间隔，不是中间点数：中间点数 = d−1；本题 d = 3 而不是 2。
  • ÷k 是消除「从哪个选中点开始数」的重复，不是除以排列数；镜像通常不合并，只有题目明说「翻转后相同」才按项链处理。
