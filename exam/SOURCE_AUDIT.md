# 竞赛题目来源审计（T7，2026-11-08）

## 1. 审计口径

本审计将数学答案核验与题目来源认证分开。仓库中存在 PDF、答案页、逐题解析或第三方网页转载，都不自动等于赛事主办方来源认证。

- **A｜官方原始来源已核验**：主办方/承办方官网或可验证官方账号发布的原卷，且能与仓库文件逐页或通过文件哈希确认一致。
- **B｜独立第三方旁证**：第三方页面能确认赛事名称、届次、卷名或部分题面，但不是主办方原始发布；不能表述为官方认证。
- **C｜仅仓库本地文件**：仓库有 PDF/答案/录入记录，但未找到足以证明来源的独立原始发布记录。
- **D｜汇编/训练材料**：本身不是一套原始竞赛卷；题目来源需要逐题追溯。

## 5. 发现的分类与质量问题

1. **18 份不等于 18 套正式真题。** 2024 IHC 6培训题是训练材料；考前60题是练习汇编，应从正式赛事卷数量中剔除。
2. IHC A/C/D-6、2025 IHC J-6、2026 IHC S-6 文件名中的“发布版”不等于官方发布证据；获得组织方源链接前，统一称“IHC发布版（来源待认证）”。
3. 2024年1月世少赛地区卷 JSON 注明没有官方答案页，且第10、12题图形/条件辨识待核；来源认证与题目内容复核是两个独立问题。
4. 考前60题必须逐题标明“原题（注明赛事/年份/卷号/题号）”“改编题”或“原创题”；没有证据的条目不得继续标为竞赛真题。
5. 当前 JSON 的 source 字段只指向仓库内 PDF 路径，不是外部出处。建议后续扩展 source_provenance 字段，至少包括 source_type、organizer、official_url、retrieved_at、file_sha256、verification_status。

## 6. 推荐的后续补证流程

- 向资料提供者索取原始下载地址、发布通知、原始文件及答案文件；保留邮件/网页存档信息。
- 对官方站点或官方公众号文章保存 URL、标题、发布日期、截图/网页归档；下载文件计算 SHA-256，与仓库 PDF 比对。
- 若只能找到第三方转载，记录转载平台与页面，状态保持 B，不改写为官方真题。
- 对考前60题汇编，逐题追溯源卷；找不到的改标原创/来源待核，不得引用到正文作为某届赛事考察证据。
- 对来源无法证实的卷，保留为“来源待认证的练习材料”，数学解析可继续使用，但不计入已认证真题统计。
