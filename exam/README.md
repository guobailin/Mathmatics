# 六年级竞赛试卷与训练资料（走美 / WMO / IHC / 世少赛）

本目录收录 18 份六年级竞赛/测评/训练资料的学生版 PDF，以及逐题录入与解答；其中含训练题与考前汇编，不应全部称作正式竞赛真题。来源分级见 [SOURCE_AUDIT.md](SOURCE_AUDIT.md) 与 [SOURCE_REGISTER.csv](SOURCE_REGISTER.csv)。有官方答案页的已逐题核对；无答案页的为独立推导，部分图形题在解析中注明了读图口径。

## 年级口径说明

1. 本目录 18 套卷**全部是六年级竞赛卷**，不代表其他年级有自己的独立卷次。
2. 各知识点正文「竞赛真题中的考察」列出的是**该题在六年级卷中的出现位置**；四、五年级的知识点引用六年级卷，说明的是"这个考点在六年级卷里怎么考"，**不表示四年级就要掌握到该难度**。
3. 知识点自身 frontmatter 的 `grade` 字段才是"建议学习年级"的权威口径。

## 星标口径说明

本题库有**两套星标**，语义不同，不要互相换算：

| 位置 | 范围 | 含义 |
|---|---|---|
| 知识点例题标题，如 `### 例1：…（★★★）` | **1–5 星** | 该题在**本篇内部的梯度位次**：★★ 入门、★★★★★ 压轴 |
| 知识点「竞赛真题中的考察」条目 | **1–7 星** | 该题在**原卷中的绝对难度**，直接照抄 `exam/answers/` 里该题的 `**难度**：★k` |

真题条目不因为超过 5 星就截断——那会把原卷的难度判断改掉。看到 ★6、★7 只说明这道题在原卷里就是最难的档，与例题的 ★★★★★ 不是同一把尺子。

## 目录说明

- `*.pdf`：原始试卷（学生版），部分卷末附官方答案。
- `answers/`：逐题 Markdown 解答 + 机器可读 JSON（题号、知识点、方法、难度、答案）。
- `answers/_review-*.md`：交叉复核记录（如有）。
- `answers/2024思维能力全国总测评六年级答案.md`：2024 全国总测评纯答案转录。
- `answers/【六年级】世少赛备考资料2024版-index.md`：88 页世少赛备考资料合集索引（6 真题卷 + 8 模拟卷 + 答案页）。
- `answers/_book-part1..4.md`：合集索引的分段底稿。
- `_rendered/`：逐页 PNG 与文本层缓存，由 `tools/render_exam.py` 生成，已 gitignore。

```bash
python3 tools/render_exam.py       # PDF → 逐页 PNG + text.txt
python3 tools/build_exam_index.py  # 生成 SUMMARY.md，并把真题索引写回 content/
```
