一、底层只有三条原理 THE ONLY THREE RULES

原理公式说明与用途
凑整 298 + 457 = 300 + 457 − 2 把数看成"整十整百 ± 零头"。加减法全部靠它。
分配律 (a + b)·c = a·c + b·c 把难乘的数拆开（99 = 100 − 1，15 = 10 + 5）。
平方差 a² − b² = (a + b)(a − b) ★ 最通用的乘法技巧：两数同奇偶（平均数为整数）就能用，乘法变减法。
统一思想：几乎所有巧算都在做同一件事——制造"好算的数"或"可抵消的项"。 凑整是制造整数，基准数法是让零头互相抵消，裂项是让中间项互相抵消。看穿这一点，技巧就不用背了。
心法：先估量级 → 再精算 → 最后检验。巧算的价值不是"快"，而是算错时自己知道。

三、加减法：先找伙伴，再找基准 ADD & SUB

3.1 加法的三种打法

① 配对凑整 38 + 47 + 62 + 53 = (38+62) + (47+53) = 200 信号：尾数互补（8+2、7+3）。4 个数以上相加，先分组。
② 基准数法 78 + 81 + 79 + 82 + 80 = 80×5 + (−2+1−1+2+0) = 400 信号：所有数都贴着同一个整数。
③ 少加多减 298 + 457 = 300 + 457 − 2 = 757 − 2 = 755 信号：末位是 8、9 或 98、99。
④ 补零凑整 999+998+997+996 = 1000×4 − (1+2+3+4) = 3990 "全补到整数，再减掉补的部分"。

5.3 分数裂项（求和神器）

公式例子
1/[n(n+1)] = 1/n − 1/(n+1) 1/(1×2) + ⋯ + 1/(9×10) = 1 − 1/10 = 9/10
1/[n(n+k)] = (1/k)·[1/n − 1/(n+k)] 1/(1×3)+1/(3×5)+1/(5×7) = ½(1 − 1/7) = 3/7
2/[n(n+2)] = 1/n − 1/(n+2) 2/(1×3)+2/(3×5) = 1 − 1/5 = 4/5
n/[n(n+1)] = 1/(n+1) 1/2 + 2/6 + 3/12 = 1/2 + 1/3 + 1/4 = 13/12
识别信号：分母是两个连续（或等间隔）整数之积时，立刻考虑裂项。 裂项的本质不是"公式"，而是制造可以成对抵消的中间项——和加法配对凑整是同一思想。
