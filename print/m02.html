列方程解应用题

年级：5、6难度：★★

一般步骤：

  1. 审：读懂题意，弄清已知与所求；
  2. 设：设未知数 $x$（问什么设什么，或设关键的小量）；
  3. 找：找出题目中的等量关系——这是列方程的灵魂；
  4. 列：根据等量关系列出方程；
  5. 解：解方程；
  6. 验：检验结果是否符合题意；答：写出答案。

找等量关系的常见依据：总数 = 各部分之和；"比……多/少"翻译成加减；"是……的几倍"翻译成乘法；路程 = 速度 × 时间等公式。

算术法 vs 方程法：算术法用已知数推出未知数（逆向思维），方程法把未知数当已知数参与列式（顺向思维）。条件关系复杂、"倒推"困难的题（如"比一个数的几倍多几"），方程法往往更简单。

反比例

年级：6难度：★★

意义：两种相关联的量，一种量变化，另一种量也随着变化，如果相对应的两个数的乘积一定，这两种量叫成反比例的量。
$$x \times y = k \text{（一定）}$$

判断方法：① 相关联；② 变化方向相反（一个扩大另一个缩小）；③ 乘积是否一定。

常见反比例：路程一定时，速度与时间；总价一定时，单价与数量；工作总量一定时，工作效率与时间。

反比例解决问题：乘积一定 → 列方程 $a_1 b_1 = a_2 b_2$ 求解。

对比记忆：正比例"比值一定，同大同小"；反比例"乘积一定，一大一小"。

正比例

年级：6难度：★★

意义：两种相关联的量，一种量变化，另一种量也随着变化，如果相对应的两个数的比值（商）一定，这两种量叫成正比例的量，关系叫正比例关系。
$$\frac{y}{x} = k \text{（一定）}$$

判断方法（三步）：① 两种量是否相关联；② 变化方向是否一致（一个扩大另一个也扩大）；③ 比值是否一定——这是关键。

常见正比例：速度一定时，路程与时间；单价一定时，总价与数量；工作效率一定时，工作总量与时间。

正比例解决问题：比值一定 → 列比例 $\frac{a_1}{b_1} = \frac{a_2}{b_2}$ 求解。

易错点：圆的面积与半径不成正比例（$\frac{S}{r} = \pi r$，比值随 $r$ 变化）；正方形的周长与边长成正比例（比值恒为 4）。

比例尺

年级：6难度：★★

意义：一幅图的图上距离与实际距离的比，叫这幅图的比例尺。
$$\text{比例尺} = \frac{\text{图上距离}}{\text{实际距离}}$$

两种形式：数值比例尺（如 1:1000000，表示图上 1 厘米相当于实际 1000000 厘米 = 10 千米）；线段比例尺（图上标一段代表实际多少）。

三个量的关系：图上距离 = 实际距离 × 比例尺；实际距离 = 图上距离 ÷ 比例尺。

操作要点：计算前统一单位（一般把实际距离化成厘米）；求图上距离时用乘法，求实际距离时用除法，也可统一列比例。

易错点：比例尺 1:500 是一个比，不带单位；"比例尺 50:1"是放大比例尺（精密零件图），图上 50 厘米对应实际 1 厘米。

比例的意义与基本性质

年级：6难度：★★

比例：表示两个比相等的式子，如 $2 : 3 = 4 : 6$。两端的两项叫外项，中间的两项叫内项。

比例的基本性质：在比例里，两个外项的积等于两个内项的积。
$$a : b = c : d \Rightarrow ad = bc$$
这又叫"交叉相乘相等"，是解比例和判断比例的钥匙。

判断两个比能否组成比例：方法一，分别求比值看是否相等；方法二，假设组成比例，看交叉相乘是否相等。

易错点：比例是"两个比相等"的式子，单独一个比不是比例；写比例时注意顺序，$2:3 = 4:6$ 成立，$2:3 = 6:4$ 不成立。

比的基本性质与化简

年级：6难度：★

比的基本性质：比的前项和后项同时乘或除以相同的数（0 除外），比值不变。

化简比：把比化成前项后项互质的最简单的整数比。

  • 整数比：同除以最大公因数，如 $24 : 36 = 2 : 3$；
  • 小数比：先同乘 10、100 化成整数比，再约分；
  • 分数比：先同乘分母的最小公倍数化成整数比，再约分；
  • 带单位的比：先统一单位再化简。

化简比 vs 求比值：化简比的结果仍是一个比（如 2:3），求比值的结果是一个数（如 $\frac{2}{3}$）。这是最易混淆的两件事。

比的意义

年级：6难度：★

意义：两个数相除又叫两个数的比。"$a$ 比 $b$"写作 $a : b$，$a$ 叫前项，$b$ 叫后项（后项不能为 0）。

比值：前项 ÷ 后项所得的商，可以是整数、小数或分数，如 $3 : 4 = \frac{3}{4}$。

比、除法、分数的关系：

| 比 | 前项 | :（比号） | 后项 | 比值 |
|---|---|---|---|---|
| 除法 | 被除数 | ÷ | 除数 | 商 |
| 分数 | 分子 | 分数线 | 分母 | 分数值 |

比与比值的区别：$a : b$ 表示一种关系，比值是一个数。"3:4"读作三比四。

易错点：体育比赛中的"3:0"不是数学上的比（后项不能为 0，它只记录比分）；带单位的同类量求比要先统一单位。

用字母表示数

年级：5难度：★

意义：用字母可以表示任意的数、运算定律（$a+b=b+a$）、公式（$S = ah$）和数量关系，让表达更简洁、更一般。

省略写法：字母与数、字母与字母相乘，乘号可记作"·"或省略不写，数写在字母前面：$a \times 3 = 3a$，$a \times b = ab$。$a \times a = a^2$（读作 a 的平方），注意 $2a = a + a$ 与 $a^2 = a \times a$ 完全不同。

代数式求值：把字母换成指定的数，按运算顺序算出结果。求值时要把省略的乘号补回来。

易错点：$a^2$ 不一定大于 $2a$（如 $a = 1$ 时 $a^2 < 2a$）；字母后面带单位时，式子要加括号，如"$(3a + 2)$ 元"。

等式的性质

年级：5难度：★

等式：用等号连接、左右两边相等的式子，如 $20 + 30 = 50$、$x + 3 = 9$。等式就像一架平衡的天平。

性质 1：等式两边同时加上或减去同一个数，等式仍然成立。
$$a = b \Rightarrow a + c = b + c$$

性质 2：等式两边同时乘同一个数，或同时除以同一个不为 0 的数，等式仍然成立。
$$a = b \Rightarrow ac = bc; \quad a = b \Rightarrow a \div c = b \div c \ (c \neq 0)$$

等式的性质是解方程的依据：解方程的每一步"两边同时……"都是在用这两条性质。

易错点：除以的数不能为 0；"同时"意味着两边必须做完全相同的操作，只动一边就破坏了平衡。

例题

解比例

年级：6难度：★★

解比例：根据比例的基本性质（外项积 = 内项积），先把比例转化成方程，再求解。

步骤：$a : b = c : x \Rightarrow ax = bc \Rightarrow x = \dfrac{bc}{a}$

分数形式的比例同样用交叉相乘：$\dfrac{a}{b} = \dfrac{c}{x} \Rightarrow ax = bc$。

检验：把求得的值代入原比例，看两个比的比值是否相等（或交叉相乘是否相等）。

应用：解比例广泛用于按比例分配、比例尺、图形的放大缩小等问题。

认识方程与解方程

年级：5难度：★★

方程：含有未知数的等式，如 $x + 3 = 9$。两个条件缺一不可：$3 + 5 = 8$ 不是方程（无未知数），$x + 3$ 也不是方程（不是等式）。

方程的解：使方程左右两边相等的未知数的值；求方程的解的过程叫解方程。

解方程的依据：等式性质。常见类型：

  • $x + a = b \Rightarrow x = b - a$
  • $x - a = b \Rightarrow x = b + a$
  • $ax = b \Rightarrow x = b \div a$
  • $x \div a = b \Rightarrow x = b \times a$
  • 两步型 $ax + b = c$：先两边减 $b$，再两边除以 $a$。

检验：把解代入原方程，看左右两边是否相等——这是必须养成的习惯。

易错点：$3x = 0$ 的解是 $x = 0$，不是"无解"；解 $x \div 5 = 20$ 两边同乘 5，不是除以 5。

左边减了 5，右边也要减 5；左边除以 3，右边也要除以 3。

答案：

5；3

等式的性质 · 例2：判断变形是否正确

①②③分别用了性质 1 和性质 2，正确。④ 当 $c = 0$ 时不成立，题目没说明 $c \neq 0$，错误。

答案：

①②③正确；④错误（未排除 c = 0）

解比例 · 例1：解比例

① $4x = 12 \times 5 = 60$，$x = 15$。② 交叉相乘：$1.5x = 2.5 \times 6 = 15$，$x = 10$。

答案：

$x = 15$；$x = 10$

解比例 · 例2：解比例的应用

设需加水 $x$ 克。$1 : 100 = 25 : x$，即 $x = 100 \times 25 = 2500$ 克。

答案：

2500 克

认识方程与解方程 · 例1：解一步方程

$x - 4.5 = 7.8$，两边同加 4.5，$x = 12.3$。检验：$12.3 - 4.5 = 7.8$ ✓。$1.2x = 9.6$，两边同除以 1.2，$x = 8$。检验：$1.2 \times 8 = 9.6$ ✓。

答案：

$x = 12.3$；$x = 8$

认识方程与解方程 · 例2：解两步方程

$3x + 6 = 27$：两边同减 6 得 $3x = 21$，再同除以 3 得 $x = 7$。$5x - 12 = 48$：两边同加 12 得 $5x = 60$，$x = 12$。

答案：

$x = 7$；$x = 12$
